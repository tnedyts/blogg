# Skyblog

Готовий статичний сайт блогу для GitHub Pages.

## Як опублікувати на GitHub Pages

1. Створіть новий репозиторій на GitHub, наприклад `skyblog`.
2. Завантажте до його кореня три файли з цієї папки: `index.html`, `styles.css` та `app.js`.
3. На GitHub відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** виберіть **Deploy from a branch**, гілку `main` і папку `/(root)`.
5. Збережіть зміни. За кілька хвилин GitHub покаже адресу сайту.

## Важливо про акаунти

У цій версії реєстрація, вхід та створені дописи зберігаються в `localStorage` — лише в браузері конкретного відвідувача. Це дозволяє безпечно демонструвати роботу сайту на GitHub Pages без сервера.

Якщо потрібні справжні акаунти, спільні дописи та авторизація на різних пристроях, треба підключити серверну службу (наприклад, Firebase або Supabase).
